# 中文标量公式与真值表校订记录

本记录对应 `scripts/text-formulas.js`。公式内容逐图读取本地 EPUB 原始资源，转写成可选择的 HTML 文字、变量、上下标、上划线和表格。原始 EPUB/PDF 不被修改。英文数据不参与中文正文生成。韩林合与贺绍甲正文分别直接从各自 EPUB 解析，本模块只转写公式资源、校订下列明确的数学编码缺陷，并附加用于复制的 `data-latex`。

## 原始来源

- 韩林合：`维特根斯坦文集（套装全8卷） (维特根斯坦) (z-library.sk, 1lib.sk, z-lib.sk).epub`，第 2 卷，`OEBPS/Text/part0024.xhtml` 至 `part0026.xhtml` 与 `OEBPS/Images`。

- 贺绍甲：`逻辑哲学论 ([奥地利] 路德维希·维特根斯坦贺绍甲) (z-library.sk, 1lib.sk, z-lib.sk).epub`，`OEBPS/text00007.html` 与同目录原始 JPEG。

原有行内 `<sub>`、`<sup>` 与 `.mathmode` 被标注为可复制公式；相邻片段组合成完整的运算、比值和等式语义。转换保留所有 525 条的中文文字，不以旧的整段格式覆盖重写译文。独立测试逐条比较公式转写前后的中文文字，同时检查真值表行序、空单元格、上下限、各译本特有符号、校订位置、复制数据与重复执行的一致性。

公式块内原有的中文引号和句点在复制元数据中以 `\text{“}`、`\text{”}`、`\text{。}` 保存，正文显示仍使用原标点；`Def.` 使用 `\mathrm{Def.}` 保存正体定义标记。

来源中带有真实换行的居中数学块（如韩 6.241、6.02 的定义序列）复制时使用 `\begin{gathered}…\end{gathered}`，避免在单个数学环境中使用没有多行容器的 `\\`。网站原来的 HTML 换行保持不变。
